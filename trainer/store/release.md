# Выпуск PRO Trainer — что и куда вписывать

Пошагово, от пустой консоли до кнопки «Отправить на проверку». Все значения
взяты из кода — если поменять их в консоли, приложение перестанет узнавать
свои же подписки.

Тексты описаний, ключевые слова и подписи к скриншотам — в `listing.md`.
Скриншоты — `node trainer/store/shots.js`, результат в `store/out/<язык>/`.

## Подписки

> **Сейчас этот раздел не нужен.** Сборка для магазинов идёт бесплатной и
> ничего не продаёт внутри: `native/scripts/sync-web.js` без ключа `--sell`
> ставит флаг `PRO_TRAINER_FREE`, и приложение убирает и покупку, и все
> ссылки, которые вели бы на оплату. Деньги приходят напрямую от клиента на
> сайте — магазин не берёт комиссию, а ФОП может оставаться на 2 группе.
>
> Раздел ниже понадобится, когда встроенные покупки включат обратно: тогда
> собирать с `--sell`, завести товары в консолях и выпустить новую версию.

Идентификаторы должны совпасть с кодом посимвольно. В приложении они лежат в
`PLANS` (`index.html`), на сервере — в `api/_lib.js`, в мосте к магазину — в
`native/iap-bridge.js`. Проверка `trainer/tests/consistency.js` следит, чтобы
эти три места не разошлись, но за консоль магазина она отвечать не может.

| Идентификатор | Период | Цена на сайте | Цена в магазине |
|---|---|---|---|
| `pro_trainer_monthly` | 1 месяц | **299 ₴** | $4.99 |
| `pro_trainer_quarterly` | 3 месяца | **749 ₴** | $12.99 |
| `pro_trainer_yearly` | 1 год | **1990 ₴** | $49.99 |

Платит человек по левой колонке: подписку продаёт сайт, гривной, через LiqPay.
Правая колонка — цена продукта в консоли магазина; она понадобится в тот день,
когда встроенные покупки включат, и до тех пор нигде не показывается.
**Внимание:** Apple запрещает уводить пользователя из приложения на свою оплату
и даже упоминать её в приложении. Поэтому в магазинных сборках кнопки оплаты
нет вовсе, а адрес кабинета показан обычным текстом, не ссылкой.

Все три подписки — в одной группе подписок (Subscription Group), иначе человек
не сможет перейти с месячной на годовую без отмены.

## App Store Connect

### 1. Приложение

1. **My Apps → +** → New App, платформа iOS.
2. Name: `PRO Trainer`, Primary Language: Ukrainian, Bundle ID: `com.protrainer.app`, SKU: `protrainer`.
3. **App Information**: категории, права (ФОП Мозолевич Андрей), возрастной рейтинг.
4. **Pricing**: приложение бесплатное, доход — от подписок.

### 2. Подписки

**Monetization → Subscriptions → +** → группа `PRO Trainer`, внутри три подписки
из таблицы выше. У каждой:

- Reference Name — понятное имя для консоли, например «Місяць».
- Duration — 1 месяц / 3 месяца / 1 год.
- Price — из таблицы, в долларах; остальные страны Apple пересчитает сам.
- Localization — название и описание на украинском (и на остальных языках, если
  хочешь показывать их в других странах).

**Пробный период в консоли заводить не нужно.** Наши 14 дней считает сервер, а
не магазин. Если завести ещё и Introductory Offer, человек получит два пробных
периода подряд.

### 3. Тексты и картинки

Из `listing.md`: имя, подзаголовок, описание, ключевые слова, промотекст.
Скриншоты — `store/out/<язык>/ios-*.png`, размер 1290×2796, ровно то, что
требует App Store для 6.7". Иконка — `store/out/icons/app-store-1024.png`
(`node trainer/store/icons.js`), без прозрачности и без скруглённых углов:
Apple накладывает маску сама, а скруглённую обрежет второй раз.

### 4. App Privacy

Отвечать по разделу «App Privacy» в `listing.md`. Коротко: данные клиентов не
собираются и не покидают устройство; на сервер уходит только логин, обезличенный
идентификатор устройства и срок подписки — для работы самой подписки. Трекинга
и рекламы нет.

### 5. Сборка

Собирается на Mac, с телефона нельзя:

```bash
cd trainer/native
npm install
npm run sync:web
npx cap add ios
npm run ios            # откроется Xcode
```

В Xcode: подписать своим Team, поднять версию, Product → Archive → Distribute.

**Перед архивом** подставить ключи в `native/iap-bridge.js` (`CONFIG.apiKeyIos`,
`apiKeyAndroid`) — сейчас там заглушки, и покупка молча не сработает.

### 6. Заметка для проверяющего

Проверяющему нужен рабочий вход. Написать в App Review Information:

> Реєстрація не потребує підтвердження: введіть будь-яку пошту, наприклад
> `review@apple.com`, і застосунок одразу відкриється з 14-денним пробним
> періодом. Дані зберігаються на пристрої, сервер потрібен лише для підписки.

## Google Play Console

### 1. Приложение

1. **Create app**: название `PRO Trainer`, язык — украинский, тип — App, бесплатное.
2. **Store listing**: тексты из `listing.md`, скриншоты `store/out/<язык>/play-*.png`
   (1080×1920), иконка `store/out/icons/play-512.png`, обложка
   `store/out/icons/play-feature-1024x500.png` — всё делает `node trainer/store/icons.js`.
3. **App content**: политика конфиденциальности, декларации по рекламе (нет),
   целевой аудитории (взрослые), безопасности данных (как в App Privacy выше).

### 2. Подписки

**Monetize → Subscriptions** → те же три идентификатора, те же цены, базовый план
у каждой с автопродлением. Пробный период (free trial) в консоли **не заводить**
по той же причине, что и в Apple.

### 3. Сборка

Файл `.aab` собирается в GitHub Actions, компьютер не нужен:

1. **Actions → Android → Run workflow**, вписать версию (например `1.0.0`).
2. Дождаться, скачать артефакт `protrainer-aab`.
3. Загрузить в **Testing → Internal testing**, потом в Production.

Перед первой загрузкой нужен ключ подписи — четыре секрета в репозитории:
`ANDROID_KEYSTORE` (файл `.jks` в base64), `ANDROID_KEYSTORE_PASSWORD`,
`ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`. Как его сделать — в `native/README.md`.
