# Як прогнати справжні чеки

Поки цього не зроблено, точність сканера — здогад. Тут по кроках, що
саме треба зробити, щоб вона стала виміряною цифрою.

Разова робота на 15–20 хвилин. Два шляхи: на комп'ютері або зовсім без
нього, з телефона.

## Що знадобиться

1. **Ключ API.** Це НЕ те саме, що підписка Claude — вона ключа не дає
   і оплату API не покриває. Ключ береться окремо:
   [console.anthropic.com](https://console.anthropic.com) → Billing →
   поповнити рахунок → API keys → Create key. Ключ показують один раз,
   збережіть одразу.

2. **Гроші на рахунку.** Прогін 30 чеків у всіх трьох режимах коштує
   приблизно **$4–5**. Закладіть $10 — вистачить із запасом на другий
   прогін, якщо доведеться перезнімати частину фото.

3. **20–30 фото чеків** із різних мереж — АТБ, Сільпо, Novus, Varus,
   локальні магазини. Чим різноманітніше, тим кориснішим буде результат:
   мета — знайти, де сканер ламається, а не підтвердити, що він працює.

   Знімайте так, як зніматиме людина: не розгладжуючи, при звичайному
   світлі, з рук. Ідеально відскановані чеки нічого не перевіряють.

   **Формат — JPEG, не HEIC.** iPhone за замовчуванням знімає в HEIC,
   якого модель не приймає. Або переставте камеру: Налаштування → Камера
   → Формати → **Найсумісніший**. Або просто завантажуйте фото через
   Safari — iOS зазвичай конвертує їх у JPEG сам.

## Шлях А · на комп'ютері

Найпростіший і найприватніший: фото нікуди не виїжджають, окрім самих
викликів API.

```bash
git clone https://github.com/wf6zn6n9wm-ux/Shopik.git
cd Shopik/holodylnyk/scanner
npm install
```

Покладіть фото в теку `photos/` поруч і женіть три режими:

```bash
export ANTHROPIC_API_KEY=sk-ant-…

node tools/batch.js ./photos reports/ladder.md                    # сходинками
AI_MODEL_FALLBACK='' node tools/batch.js ./photos reports/cheap.md
AI_MODEL=claude-opus-5 AI_MODEL_FALLBACK='' \
  node tools/batch.js ./photos reports/expensive.md
```

Якщо `node` не встановлений: `brew install node`, або завантажити з
[nodejs.org](https://nodejs.org) — потрібна версія 20 або новіша.

## Шлях Б · з телефона, без комп'ютера

Прогін робить GitHub Actions, ви тільки тиснете кнопку в браузері.

> **Спершу приватний репозиторій.** `wf6zn6n9wm-ux/Shopik` **публічний**.
> На чеку видно магазин, дату, весь список покупок, а часто й останні
> цифри картки. Викладені туди фото побачить будь-хто, і вони лишаться
> в історії git назавжди — видалити файл цього не виправляє.
>
> Тому: github.com → New repository → **Private**. Або перемкніть
> існуючий: Settings → General → Danger Zone → Change visibility.

1. **Покладіть у репозиторій код.** Якщо створили новий — скопіюйте туди
   теку `holodylnyk/` і файл `.github/workflows/receipts.yml`.

2. **Додайте ключ.** Settings → Secrets and variables → Actions →
   New repository secret. Ім'я рівно `ANTHROPIC_API_KEY`, значення — ключ.
   Після збереження його не видно навіть вам: це нормально.

3. **Завантажте фото.** Add file → Upload files, створіть теку `receipts`
   і перетягніть туди знімки. З iPhone це працює прямо із Safari.

4. **Запустіть.** Вкладка Actions → «Прогін чеків» → Run workflow →
   режим `all` → зелена кнопка.

5. **Заберіть звіти.** Хвилин через 5–15 у тому ж запуску внизу з'явиться
   artifact `reports` — три файли `.md`.

Запуск лише ручний, навмисно: жодного `push`, жодного розкладу, щоб
випадковий коміт не витратив гроші.

## Що дивитися у звіті

| Розділ | Питання, на яке він відповідає |
|---|---|
| Числа прочитані вірно | Чи сходиться сума позицій із підсумком. Це найсильніша перевірка без ручної звірки. |
| Скільки це коштує | Ціна одного чека й **частка ескалацій** — головне число: саме воно визначає, скільки все це коштуватиме на тисячі людей. |
| Слова, яких немає у словнику | Готовий список кандидатів у `lib/dictionary.js`. Кожне додане слово назавжди знімає одну позицію з моделі. |
| Для ручної звірки | Назви позицій — їх треба звірити з фото очима. Автоматично це не перевіряється ніяк. |

Порівнюйте `cheap.md` з `expensive.md`: якщо дешева модель читає майже
так само, дорога не потрібна зовсім, і ціна падає вп'ятеро. Якщо
розходяться — `ladder.md` показує, скільки коштує компроміс.

Головне, чого чекаємо: **не «все чудово», а список того, що зламалось.**
Кожен чек, який не зійшовся, — це або нове слово у словник, або
виправлений промпт. Саме цим сканер і стає кращим.
