# Шрифт Inter (локальный бандл)

Для офлайн-работы и премиум-типографики Inter бандлится локально, а не тянется
через сеть. Положите сюда **один** вариативный файл:

```
assets/fonts/Inter-Variable.ttf
```

## Где взять

- Официально: https://rsms.me/inter/ → скачать → `Inter.ttf`/`InterVariable.ttf`
  (переименовать в `Inter-Variable.ttf`).
- Или Google Fonts: https://fonts.google.com/specimen/Inter → «Download family»,
  внутри `Inter[opsz,wght].ttf` → переименовать в `Inter-Variable.ttf`.

Лицензия SIL OFL — свободно для бандла в приложение.

## Как это работает

`pubspec.yaml` регистрирует семейство `Inter` с этим файлом. Точные веса
(400/500/600/700) задаются в коде через `fontVariations` (`lib/design/typography.dart`),
поэтому одного вариативного файла достаточно.

Пока файла нет — приложение запускается на системном шрифте (офлайн, без ошибок);
после добавления — типографика становится пиксель-в-пиксель по дизайн-системе.
