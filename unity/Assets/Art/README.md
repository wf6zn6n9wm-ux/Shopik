# Art (графика)

Здесь лежат исходные ассеты графики. Проект намеренно **не использует** чужие
изображения, персонажей или интерфейсы — стиль оригинальный: яркая мультяшная
графика, мягкие формы, дружелюбные цвета.

## Что подготовить

| Категория | Где используется | Формат |
|-----------|------------------|--------|
| Фоновые иллюстрации сцен | `Resources/Backgrounds/<id>` или Addressables-адрес `Backgrounds/<id>` | PNG, ~2048×1536, спрайт |
| Превью уровней | `Resources/Thumbs/<id>` | PNG, 512×384 |
| Иконки предметов | адрес `Icons/<itemId>` | PNG с альфой, 128×128 |
| Иконки бустеров | адрес `Icons/booster_<type>` | PNG, 128×128 |
| UI-атлас (кнопки, панели) | UI-префабы | 9-slice спрайты |

Адрес в данных (`AssetRef.Address`) — это либо путь в `Resources`, либо ключ
Addressables (если включён символ компиляции `FINDORIA_ADDRESSABLES`).

## Палитра (рекомендация)

- Основной: `#FFB84C` (тёплый жёлтый), `#7A4FD0` (фиолетовый), `#57C22F` (зелёный).
- Фон UI: тёплый кремовый `#F3E8D2`.
- Акцент: `#FF6FAE` (розовый), `#5EC8FF` (голубой).

Никакие ассеты сюда пока не коммитятся — это заглушка структуры.
