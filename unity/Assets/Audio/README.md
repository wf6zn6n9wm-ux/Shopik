# Audio (звук)

Оригинальные звуки и музыка. Клипы регистрируются в компоненте `AudioService`
(поле «Банк клипов»: пары `id → AudioClip`). Код обращается к ним по строковому
`id`, поэтому сами файлы можно менять без правки кода.

## Ожидаемые идентификаторы клипов

| id | Когда играет |
|----|--------------|
| `music_menu` | Музыка в меню |
| `music_game` | Музыка на уровне |
| `sfx_found` | Найден предмет |
| `sfx_wrong` | Промах (неверное нажатие) |
| `sfx_win`   | Победа |
| `sfx_lose`  | Поражение |
| `sfx_click` | Нажатие кнопки UI |
| `sfx_reward`| Получение награды |

Форматы: короткие SFX — WAV/OGG mono; музыка — OGG, зациклённая. Это заглушка
структуры: реальные аудиофайлы добавляются позже и назначаются в инспекторе.
