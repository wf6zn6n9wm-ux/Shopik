# Деплой «Гантеля» + реальний AI-рефері

Прототип складається зі статичного `index.html` та однієї serverless-функції
`api/referee.mjs`, яка аналізує фото чек-іну штучним інтелектом. Білд не потрібен.

Рефері працює **тільки на задеплоєній версії** (там є бекенд + ключ). На демо-файлі
`demo.html` та в Artifact-посиланні рефері лишається в demo-режимі — це нормально.

---

## Крок 1. Отримати API-ключ
1. **console.anthropic.com** → **API Keys** → **Create Key**.
2. Скопіюй ключ (`sk-ant-…`).
3. У **Billing** поповни баланс на кілька $ — кожен чек-ін = 1 запит vision (коштує копійки).

## Крок 2. Влити код у `main`
Vercel за замовчуванням деплоїть гілку `main`. Код лежить у гілці PR.
- Відкрий PR на GitHub → **Merge pull request**.
- Або в Vercel → Project → Settings → Git → зміни production-гілку на робочу.

## Крок 3. Задеплоїти на Vercel
1. **vercel.com** → увійди через GitHub → **Add New… → Project**.
2. **Import** репозиторій `wf6zn6n9wm-ux/Shopik`.
3. Налаштування лишити як є:
   - **Framework Preset:** Other
   - **Build Command:** порожньо
   - **Root Directory:** `./`
4. Розгорни **Environment Variables** і додай:

   | Name | Value |
   |------|-------|
   | `ANTHROPIC_API_KEY` | твій `sk-ant-…` (обовʼязково) |
   | `REFEREE_MODEL` | `claude-sonnet-5` (опційно; для економії — `claude-haiku-4-5-20251001`) |

5. **Deploy**.

## Крок 4. Перевірити
Відкрий виданий `*.vercel.app` → **Челендж → Зробити чек-ін → фото → «Відправити рефері»**.
Фото реально піде в AI, вердикт «зал / диван» — справжній.

---

## Змінні оточення
| Змінна | Обовʼязкова | Опис |
|--------|:---:|------|
| `ANTHROPIC_API_KEY` | так | Ключ Anthropic API. Лежить лише в env Vercel, у код не потрапляє. |
| `REFEREE_MODEL` | ні | Модель vision. Дефолт `claude-sonnet-5`. |

## Як це працює технічно
- Клієнт стискає фото (макс 1024px, JPEG q0.8) і шле `POST /api/referee` з `{ image, mediaType }`.
- Функція `api/referee.mjs` викликає Anthropic Messages API з фото і промптом-суддею.
- Повертає `{ verdict: "gym"|"couch"|"unclear", confidence, reason }`.
- Якщо ключа немає або функція недоступна — фронт показує чесний банер і demo-вердикт.

## Типові проблеми
| Симптом | Причина / рішення |
|---------|-------------------|
| Банер «AI-рефері доступний лише на задеплоєній версії» | Функція недоступна або немає ключа. Перевір env `ANTHROPIC_API_KEY` та передеплой. |
| `503 no_api_key` у логах | `ANTHROPIC_API_KEY` не заданий у Vercel env. |
| `502 upstream_error` | Помилка від Anthropic (невірний ключ / немає балансу). Дивись `detail` у логах. |
| `413` / фото не відправляється | Фото завелике — стиснення вже вбудоване; перевір, що деплой свіжий. |

Логи: **Vercel → Deployment → Functions → `api/referee` → Logs**.
