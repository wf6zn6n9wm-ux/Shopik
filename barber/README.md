# Про Барбер — кабинет барбера

**твои клиенты. твой стиль. твой бизнес.**

CRM и рабочий кабинет для частного барбера и небольшого барбершопа: клиенты,
записи, услуги, расписание, деньги и переписка — в одном месте. Не витрина и не
макет: каждая кнопка что-то делает, статистика пересчитывается из данных,
изменения переживают перезагрузку.

Открывается по прямой ссылке `/barber/`. Самодостаточный `index.html`
(React 18 UMD + Babel standalone, инлайновые SVG-иконки, без сборки) — как
соседние приложения репозитория. Данные лежат в `localStorage`, сервер не нужен.

| Файл | Что это |
|---|---|
| `index.html` | весь кабинет: экраны, состояние, дизайн-система |
| `book.html` | публичная страница онлайн-записи для клиентов |
| `tests/smoke.js` | проверки без браузера: расчёты, действия, все экраны |
| `icon.svg`, `manifest.webmanifest` | иконка и PWA-манифест |
| `vercel.json` | заголовки и правило пропуска сборки |

## Дизайн-система

Две темы — один интерфейс. Меняются только значения токенов, названия и роли
одинаковые, поэтому «светлая версия» не расходится с тёмной.

| Токен | Dark | Light | Роль |
|---|---|---|---|
| `--bg` / `--bg-2` | `#0B0D0F` / `#101214` | `#F6F7F9` / `#FFFFFF` | фон |
| `--surface` / `--surface-2` | `#121517` / `#171A1D` | `#FFFFFF` / `#F4F6F8` | карточки |
| `--ink` / `--ink-2` / `--ink-3` | `#F3F5F6` / `#9AA3AA` / `#6E7880` | `#14181B` / `#5C666E` / `#8B959C` | текст |
| `--line` / `--line-2` | `#20252A` / `#2A3036` | `#E9ECEF` / `#DDE2E6` | границы |
| `--gold` / `--gold-2` | `#F5A623` / `#FFB52E` | те же | акцент |
| `--pos` / `--neg` / `--info` | `#35C07A` / `#EF5B52` / `#4A9BE8` | `#23965A` / `#D64036` / `#2A78C8` | статусы |

- **Типографика** — Inter, `tabular-nums` на всех числах.
- **Радиусы** — 8 / 10 / 12 / 14 / 18 / 999.
- **Сетка** — 4pt, сайдбар 250px, отступы 16–24.
- **Движение** — только `transform`/`opacity`, 120–280 мс.
- Цвет — только там, где помогает читать: деньги, статус, действие.

Компоненты (все переиспользуемые): `Button`, `IconButton`, `Card`, `CardHead`,
`Badge`, `Avatar`, `Field`, `Input`, `Select`, `Area`, `Switch`, `Segmented`,
`Progress`, `Modal`, `Confirm`, `Dropdown`, `MenuItem`, `Empty`, `Toasts`,
`StatCard`, `ApptRow`, `MiniCalendar`, `LineChart`, `BarChart`, `Sidebar`,
`MobileNav`, `Icon`.

Графики — настоящие SVG-компоненты с подсказкой при наведении: меняются данные —
меняется график. Никаких картинок.

## Экраны

**Главная.** Дата, колокольчик с числом уведомлений, четыре KPI (клиенты,
записи, выручка, свободные окна — всё за сегодня и всё посчитано), карточка
следующей записи с обратным отсчётом и кнопкой «Начать запись», расписание дня,
мини-календарь с отметками, топ услуг за месяц и выручка месяца с графиком.

**Календарь.** День / Неделя / Месяц. Запись можно открыть, перенести
перетаскиванием (время округляется до шага записи), создать кликом по пустому
слоту. Выходные дни подсвечены, текущее время — красной линией.

**Клиенты.** Поиск по имени и телефону, фильтры «все / постоянные / новые /
давно не был / с записью», таблица на десктопе и список карточек на телефоне.
Карточка клиента: контакты, день рождения, визиты, средний чек, всего
потрачено, последний визит, история посещений и заметки барбера.

**Услуги.** Цена, длительность, спрос за 90 дней; добавление, правка, скрытие
из онлайн-записи, удаление. Удаление услуги не трогает историю: прошлые записи
хранят свою цену и длительность.

**Финансы.** Выручка за день / неделю / месяц / год, сравнение с прошлым
периодом (обрезанным по тот же день — иначе половина месяца всегда
«проигрывает» полному прошлому), визиты, клиенты, средний чек, самая популярная
услуга, график и выгрузка CSV.

**Сообщения.** Список диалогов с непрочитанными, переписка, быстрое напоминание
о записи. Канал внутренний; интерфейс готов к подключению Telegram, WhatsApp и
SMS в настройках уведомлений.

**Настройки.** Профиль и график работы, уведомления, валюта (USD / EUR / UAH),
язык (українська / русский / English), тема (тёмная / светлая / системная), шаг
записи, ссылка на онлайн-запись, выгрузка копии данных и сброс к демо-данным.

**Онлайн-запись** (`book.html`). Отдельная публичная страница: услуга → день →
время → контакты. Свободное время считается из графика работы и уже занятых
слотов, прошедшее не предлагается. Заявка приходит в кабинет со статусом
«заявка» — барбер принимает или отклоняет её в уведомлениях.

## Данные

Одна база в `localStorage` под ключом `probarber.v1`:

```
profile   имя, роль, фото, барбершоп, адрес, график работы по дням
settings  тема, валюта, язык, шаг записи, адрес онлайн-записи, уведомления
services  название, цена, длительность, видимость в онлайн-записи
clients   имя, телефон, день рождения, фото, заметка
appts     клиент, услуга, дата, время, длительность, цена, статус, источник
threads   переписка по клиентам
```

Статусы записи: `planned` → `active` → `done`, плюс `canceled` и `pending`
(заявка с сайта). В деньги идёт только `done`; отменённые не занимают время в
календаре.

При первом открытии база заполняется демо-данными: 58 клиентов, 8 услуг,
~1000 записей за полгода истории и три недели вперёд, сегодняшнее расписание,
две заявки с сайта и шесть диалогов. Генератор с фиксированным зерном —
демо-база одинаковая при каждом создании, а даты считаются от сегодняшнего дня,
поэтому кабинет всегда выглядит живым. База прошлой версии дополняется
значениями по умолчанию, битый JSON не роняет приложение.

## Проверки

```
node barber/tests/smoke.js
```

JSX из `index.html` и `book.html` транспилируется (bun или `@babel/standalone`)
и выполняется в песочнице с заглушкой React: каждый экран и каждая модалка
реально рендерятся, а деньги, окна, фильтры, действия и сквозной сценарий
(создать клиента → записать → провести → увидеть выручку) проверяются
отдельно. Те же проверки гоняет GitHub Actions на каждое изменение в `barber/`.
