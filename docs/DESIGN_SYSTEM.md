# Kavio — Design System (Этап 2)

> Единый визуальный язык продукта. Ноль случайных значений: каждый цвет, размер,
> отступ, радиус и длительность анимации приходит из токена. Спецификация ниже —
> источник истины для реализации во Flutter (Этап 3).
>
> **Живой style guide (визуальный):** артефакт `kavio-design-system.html` — цвета,
> типографика, spacing, тени, motion и компоненты в светлой и тёмной темах.

Направление: **тихий премиум**. Монохромная основа с холодным, чуть фиолетовым
байасом нейтралей (серый выбран, а не дефолтный) + один уверенный акцент.
Много воздуха, идеальная типографика, мягкие тени, движение со смыслом.

---

## 1. Цветовые токены

Семантические имена, а не сырые hex. Каждый токен имеет значение для **light** и
**dark**. Компоненты обращаются только к токенам, никогда к hex напрямую.

### Нейтрали

| Токен | Light | Dark | Назначение |
|---|---|---|---|
| `color.canvas` | `#FBFBFC` | `#0B0B0F` | Фон приложения |
| `color.surface` | `#FFFFFF` | `#16161B` | Карточки, листы |
| `color.surface2` | `#F4F4F7` | `#1F1F26` | Вложенные/вторичные поверхности |
| `color.surface3` | `#ECECF1` | `#292930` | Поля поиска, чипы |
| `color.ink` | `#16161A` | `#F4F4F6` | Основной текст |
| `color.ink2` | `#6A6A76` | `#9A9AA6` | Вторичный текст |
| `color.ink3` | `#9E9EAA` | `#6A6A76` | Третичный / плейсхолдеры |
| `color.line` | `rgba(22,22,40,.08)` | `rgba(255,255,255,.09)` | Хайрлайны |
| `color.line2` | `rgba(22,22,40,.14)` | `rgba(255,255,255,.16)` | Границы полей |

### Акцент (Kavio Indigo)

| Токен | Light | Dark | Назначение |
|---|---|---|---|
| `color.accent` | `#5B5BD6` | `#8B8BF0` | Главные действия, акценты |
| `color.accentPress` | `#4A4AC4` | `#7A7AE8` | Нажатое состояние |
| `color.accentTint` | `rgba(91,91,214,.10)` | `rgba(139,139,240,.15)` | Фоны, подсветка |
| `color.onAccent` | `#FFFFFF` | `#0B0B0F` | Текст/иконка на акценте |

> В тёмной теме акцент **ярче** — чтобы держать контраст и энергию на тёмном фоне.

### Семантика (отдельно от акцента, не подменяет его)

| Токен | Light | Dark | Значение |
|---|---|---|---|
| `color.success` / `successTint` | `#1F9D63` / 12% | `#3BD088` / 15% | Оплачено, подтверждено |
| `color.warning` / `warningTint` | `#C8890E` / 14% | `#E0A93B` / 16% | Ожидание, внимание |
| `color.danger` / `dangerTint` | `#DC2F35` / 12% | `#F16A6F` / 15% | Отмена, неявка, ошибка |

### Статусы записи (маппинг на токены)

`онлайн` → accent · `подтверждён` → success · `ждём/не подтверждён` → warning ·
`завершён` → ink2 (нейтраль) · `неявка/отменён` → danger.

## 2. Типографика

Одна гарнитура на весь UI. **Прод:** Inter (variable), бандл во Flutter; на iOS
допускается системный SF Pro. **Числа** (деньги, время, проценты) — всегда
`tabular-nums`. Значения токенов/технических данных — моно.

| Стиль | Размер / Интерлиньяж | Вес | Трекинг | Где |
|---|---|---|---|---|
| `type.display` | 34 / 40 | 700 | −0.022em | Крупные суммы, hero-числа |
| `type.title1` | 27 / 32 | 680 | −0.020em | Заголовок экрана |
| `type.title2` | 21 / 28 | 660 | −0.014em | Заголовок секции |
| `type.title3` | 17 / 24 | 640 | −0.008em | Подзаголовок, крупный пункт |
| `type.body` | 15 / 22 | 420 | 0 | Основной текст |
| `type.label` | 13 / 18 | 560 | 0 | Подписи, вторичные действия |
| `type.caption` | 11.5 / 16 | 640 | +0.07em, UPPERCASE | Метки, эйбрау, статусы |
| `type.mono` | 12.5–15 / 20 | 500 | 0 | Данные, время, коды |

**Правила:** длина строки основного текста ≈ 65 знаков; заголовкам —
`text-wrap: balance`; крупный кегль — плотный трекинг, тело — нейтральный;
никаких размеров вне шкалы.

## 3. Отступы (4pt-сетка)

| Токен | px | | Токен | px |
|---|---|---|---|---|
| `space.1` | 4 | | `space.6` | 24 |
| `space.2` | 8 | | `space.8` | 32 |
| `space.3` | 12 | | `space.10` | 40 |
| `space.4` | 16 | | `space.12` | 48 |
| `space.5` | 20 | | `space.16` | 64 |

**Договорённости:** экранное поле — `space.5` (20) · паддинг карточки — `space.4`
(16) · зазор между элементами списка — `space.3` (12) · между секциями — `space.8`
(32). Воздух — не роскошь, а правило: лучше больше, чем тесно.

## 4. Радиусы

| Токен | px | Где |
|---|---|---|
| `radius.xs` | 8 | Чипы, мелкие элементы, sm-кнопки |
| `radius.sm` | 12 | Кнопки, поля ввода |
| `radius.md` | 16 | Карточки, строки |

| `radius.full` | 999 | Пилюли, аватары, FAB, тогглы |

Радиус растёт вместе с площадью элемента.

## 5. Тени (Elevation)

Мягкие, низкоконтрастные. Глубину даёт **слой поверхности**, а не драматичная тень.
В тёмной теме глубина дополнительно передаётся осветлением поверхности.

| Токен | Light | Где |
|---|---|---|
| `elevation.0` | нет (плоско + `line`) | Базовые карточки на canvas |
| `elevation.1` | `0 1px 2px rgba(20,20,45,.05), 0 1px 3px rgba(20,20,45,.06)` | Карточка, stat-tile |
| `elevation.2` | `0 4px 14px rgba(20,20,45,.09)` | Bottom sheet, FAB |
| `elevation.3` | `0 12px 34px rgba(20,20,45,.14)` | Модаль, диалог |

Dark: `e1 0 1px 2px rgba(0,0,0,.4)` · `e2 0 6px 18px rgba(0,0,0,.5)` ·
`e3 0 16px 40px rgba(0,0,0,.6)`.

## 6. Motion-токены

(Полный язык движения — §10 ARCHITECTURE.md; здесь — токены значений.)

| Токен | Значение | Где |
|---|---|---|
| `motion.instant` | 100 ms | press, цвет, состояние |
| `motion.fast` | 150–200 ms | тогглы, чипы, SnackBar |
| `motion.base` | 250 ms | переход экрана, открытие листа |
| `motion.slow` | 300–350 ms | hero, полноэкранный лист |
| `ease.enter` | `cubic-bezier(0.05, 0.7, 0.1, 1)` | появление (быстро → мягко) |
| `ease.exit` | `cubic-bezier(0.3, 0, 0.8, 0.15)` | уход (быстро) |
| `ease.standard` | `cubic-bezier(0.2, 0, 0, 1)` | общий переход |
| `motion.gesture` | spring, critically damped | drag листа, перенос записи |

Правило: чем больше площадь — тем дольше, но никогда > 400 ms. `prefers-reduced-
motion` уважается (анимации отключаются/упрощаются).

## 7. Иконки

Линейные, сетка 24, обводка 1.7–2 px, скруглённые соединения/концы. Один
визуальный вес во всём приложении. Заливкой пользуемся редко — только для активного
состояния таба или акцентного действия. Библиотека — набор в стиле Lucide,
адаптированный под бренд.

---

## 8. Компоненты (анатомия и состояния)

Собираются исключительно из токенов выше. У каждого — состояния
`default / hover / pressed / focus / disabled`, крупная зона нажатия (≥44px) и
видимый фокус (`outline 2px accent, offset 2px`).

- **Кнопки:** `primary` (accent), `secondary` (surface + line2), `ghost`
  (accent-текст), `danger` (danger-tint). Размеры `md` (11×18, r-sm) и `sm`
  (8×13, r-xs). Press — scale 0.97 + понижение тени.
- **Поля ввода:** surface + `line2`; фокус — рамка accent + кольцо `accentTint`
  3px. Плейсхолдер — `ink3`. Поиск — pill на `surface3`.
- **Чипы (фильтры):** pill `surface3` / активный — accent. **Статус-пилюли:** точка
  + текст, по семантике статуса записи.
- **Toggle:** трек `surface3` → accent, кружок с `elevation.1`, ход 200 ms `enter`.
- **Аватар:** круг, `accentTint` фон + accent-инициалы (или фото).
- **Stat-tile:** surface + `elevation.1`, label (ink2) → большое число (display/
  title) → дельта (success/danger).
- **Строка клиента:** аватар + имя/подзаголовок + правая величина (tabular-nums).
- **Карточка записи:** `radius.lg`, левый цветной rail по статусу, время (tabular),
  клиент (title3), услуга/мастер (ink2), футер-действия (Начать/Перенести/Написать).
- **Bottom sheet:** верх `radius.xl`, grabber, `elevation.2`, scrim 0→40%.
  Появление 250 ms `enter`, свайп-закрытие — spring.
- **FAB / центральная ➕:** круг accent, `elevation.2`; при создании —
  container-transform в лист; прячется при скролле вниз.
- **Bottom nav:** 5 пунктов, активный — accent (заливка иконки), остальные — ink3.
- **SnackBar:** тёмный (`ink` фон / `canvas` текст), `radius.sm`, `elevation.2`,
  действие undo акцентом; авто-скрытие ~4 c; не перекрывает FAB.
- **Empty state:** пунктирная рамка `line2`, иконка в `accentTint`, заголовок +
  спокойный текст + одно действие. Никогда не «пусто ради пусто».
- **Skeleton:** shimmer из `surface2 ↔ surface3`, 1.3 c; вместо спиннеров.

## 9. Темы

Обе темы — первого класса, не инверсия. Реализация: все токены — переменные;
переопределяются под dark с сохранением контраста и работоспособности акцента на
обоих фонах. Акцент в dark ярче, тени глубже, поверхности расслаиваются осветлением.
Контраст текста соответствует WCAG AA как минимум для основного и вторичного.

---

## 10. Правила (design guardrails)

1. Ноль хардкод-значений — только токены.
2. Один акцент на экране; семантика ≠ акцент.
3. Много воздуха; при сомнении — больше отступ, а не меньше.
4. Числа — tabular; деньги и время выровнены.
5. Фокус всегда видим; зона нажатия ≥ 44px; поддержка VoiceOver/TalkBack.
6. Движение объясняет переход; > 400 ms не бывает; reduced-motion уважается.
7. Тёмная тема проверяется наравне со светлой на каждом компоненте.
