# SHARK — Telegram Mini App

Игры на звёзды (краш, рулетка, колесо, кейс), магазин подарков, рефералы и
вывод денег с **ручным подтверждением** в Telegram.

Раздел «Задания» удалён. Деньги (грн) начисляются за приглашённых друзей;
вывод — только после вашего ручного подтверждения.

## Стек

- **Фронтенд:** статический `index.html` (Telegram WebApp SDK). Вне Telegram
  или при ненастроенном бэкенде — работает как локальное демо.
- **Бэкенд:** Vercel serverless (Node) — `api/shark.js` (API) и `api/bot.js`
  (вебхук бота).
- **БД:** Supabase (PostgreSQL) через REST. Вся логика денег/звёзд — на сервере.

## Деплой (Vercel)

Отдельный проект Vercel с **Root Directory = `shark`**.

### 1. Supabase
1. Создайте проект на supabase.com.
2. SQL Editor → выполните `schema.sql`.
3. Скопируйте **Project URL** и **service_role** ключ (Settings → API).

### 2. Бот (@BotFather)
1. Создайте бота, получите токен.
2. Настройте кнопку Mini App (Menu Button → URL вашего деплоя).
3. В `api/bot.js` при необходимости поправьте `DEFAULT_APP_URL`, а в
   `index.html` — `BOT_USERNAME` (username бота для реф-ссылок).

### 3. Переменные окружения (Vercel → Settings → Environment Variables)
| Переменная | Значение |
|---|---|
| `SHARK_SUPABASE_URL` | Project URL из Supabase |
| `SHARK_SUPABASE_SERVICE_ROLE_KEY` | service_role ключ (секрет!) |
| `SHARK_BOT_TOKEN` | токен бота |
| `SHARK_ADMIN_IDS` | ваши tg_id через запятую (кому приходят заявки на вывод) |
| `SHARK_APP_URL` | URL Mini App (напр. `https://<project>.vercel.app/`) |

> Можно и без префикса `SHARK_` (`SUPABASE_URL`, `BOT_TOKEN`, `ADMIN_IDS`, …) —
> если у вас в проекте нет других сервисов с теми же именами.

### 4. Привязать вебхук бота
После деплоя один раз откройте в браузере:

```
https://<ваш-домен>/api/bot?setup=1
```

## Как работает вывод денег

1. Пользователь создаёт заявку → деньги сразу списываются с баланса (заморозка).
2. Вам (в `SHARK_ADMIN_IDS`) приходит карточка с кнопками **✅ Подтвердить / ❌ Отклонить**.
3. Выплату вы делаете **вручную** (карта/USDT), затем жмёте ✅ — пользователь
   получает уведомление.
4. ❌ Отклонить — деньги **возвращаются** на баланс пользователя.

Автоматических выплат нет.

## Безопасность

- Личность — по подписи Telegram `initData` (HMAC токеном бота); `tg_id` из тела
  запроса не доверяется.
- Балансы = сумма леджера (`shark_ledger`), движение средств — через атомарную
  идемпотентную функцию `shark_apply_ledger` (нельзя списать в минус или начислить
  дважды).
- Звёзды **не конвертируются** в деньги ни одним действием.
- Исходы игр (рулетка, колесо, краш) считает сервер; краш — provably-fair
  (хэш seed выдаётся до раунда).
