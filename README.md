# Гантеля 💪

Прототип UA-мініаппа: кидаєш гроші на власну дисципліну, щодня кидаєш фото з залу,
а **AI-рефері** вирішує — зал це чи диван. Виконав челендж → забираєш ставку **×2**.
Зірвався → ставка **згорає**.

> Це окремий новий застосунок. До попереднього вмісту репозиторію відношення не має.

## Механіка
- Кидаєш ставку (напр. 500 ₴) — вона блокується на час челленджу.
- Пройшов усі дні → отримуєш **×2** (1000 ₴).
- Пропустив день → ставка **згорає**.

## Що всередині
- **Створення челленджу** — ставка (300–2000 ₴), тривалість (7–30 днів).
- **Щоденний чек-ін з фото** — камера/галерея → вердикт AI-рефері з поясненням і впевненістю.
- **Справжній AI-рефері** — serverless-функція `api/referee.mjs` аналізує фото штучним інтелектом.
- **Гаманець** — поповнення грн/USDT (симуляція оплати), **ручний вивід**: заявка → виплата протягом 24 год.

> Виплати ×2 можуть трактуватись як парі / азартна гра — перед запуском узгодь модель з юристом.

## Запуск AI-рефері
Рефері працює на задеплоєній версії (Vercel) з env-змінною:

```
ANTHROPIC_API_KEY=sk-ant-...      # обовʼязково
REFEREE_MODEL=claude-sonnet-5     # опційно
```

Без ключа фронт показує чесний банер і дає демо-вердикт, щоб пройти сценарій кліком.

## Деплой (Vercel)
1. Import репозиторію у Vercel (фреймворк — Other, білд не потрібен, статичний `index.html`).
2. Додай `ANTHROPIC_API_KEY` у Project → Settings → Environment Variables.
3. Deploy. Функція `api/referee.mjs` піднімається автоматично як `/api/referee`.

## Локально
Достатньо відкрити `index.html` у браузері (рефері буде в демо-режимі —
serverless-функції локально без `vercel dev` не запускаються).

## Telegram Mini App
Підключено `telegram-web-app.js`. У середовищі Telegram застосунок:
- авторизується (імʼя/аватар користувача з `initDataUnsafe`);
- розгортається на весь екран, підлаштовує кольори шапки/фону;
- дає хаптик-фідбек на вердикт рефері (успіх/помилка) і на зрив;
- шерить челендж через нативний Telegram-share.

Замінити `BOT_LINK` в `index.html` на реальне посилання бота/мініаппа перед запуском.
Поза Telegram (звичайний браузер) усе працює через фолбеки (`navigator.share`/буфер).

## Стек
- Фронт: React 18 + Tailwind (CDN), один файл `index.html`, без білд-кроку.
- Бекенд: Vercel Serverless Function на Node (fetch → Anthropic Messages API).
- Telegram Mini App SDK (опційно, з фолбеками для браузера).
- Стан: `localStorage` (баланс, челендж, транзакції, заявки на вивід).
