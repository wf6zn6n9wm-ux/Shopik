# Проверки StarsHash

Приложение — один файл `starshash/index.html` без сервера, поэтому проверки
гоняют его прямо в браузере через Playwright и сверяют, что видно на экране
и что записано в `localStorage`.

## Как запустить

```bash
npm i -D playwright && npx playwright install chromium   # один раз
node tests/run.js            # все проверки
node tests/run.js hero money # только названные
```

`run.js` запускает каждую проверку отдельным процессом и в конце печатает
сводку. Код возврата — 1, если хоть что-то не сошлось.

## Что где

| файл | что проверяет | браузер |
|---|---|---|
| `source.js` | словари трёх языков сходятся, внешних запросов нет, мини-апп настроен | нет |
| `economy.js` | возврат Краша, кейсов и ПВП; окупаемость вклада | нет |
| `layout.js` | раскладка на десяти размерах, навигация не обрезана | да |
| `smoke.js` | обход всех экранов и шторок: 3 языка × 3 размера | да |
| `state.js` | битое и подложенное состояние не роняет приложение | да |
| `money.js` | бонус, вклад, пополнение, вывод, запреты | да |
| `games.js` | раунды Краша, ПВП, кейсы, журнал, сохранность, языки | да |
| `hero.js` | баланс: оформление и подгонка кегля под длинные суммы | да |
| `bonus.js` | лесенка на 60 дней, самолистающаяся полоса, отсчёт | да |
| `referral.js` | реферальная программа: 5% и никаких призов за переход | да |
| `daily.js` | ежедневные задания, сброс в полночь | да |
| `fee.js` | комиссия банка в ПВП названа и удержана | да |
| `crash.js` | обрывы в пределах закона, мгновенный обрыв, авто-вывод | да |

## Чего проверки не видят

**Надписи, вшитые в картинки.** Баннеры Краша, ПВП и Кейсов — это webp
с текстом внутри. `smoke.js` ищет непереведённый **текст**, а там текста нет,
поэтому русскую надпись в английском интерфейсе он не заметит. Такое ловится
только глазами.

**Настоящий телефон.** Всё гоняется в Chromium на десктопе. Поведение внутри
клиента Telegram, вебвью iOS и Android, кнопка «назад», свайп закрытия —
только руками.

**Платежи.** Пополнение и вывод в приложении ничего не двигают на самом деле;
проверки сверяют только арифметику внутри `localStorage`.

## Как писать новую проверку

Берите обвязку из `helpers.js`:

```js
const { браузер, открыть, жди, состояние, день, Отчёт } = require('./helpers');

(async () => {
  const о = new Отчёт('имя');
  const b = await браузер();
  const p = await открыть(b, { язык: 'ru', состояние: { bal: 1000 } });
  о.проверка('что проверяем', условие, 'пояснение');
  await b.close();
  process.exit(о.итог() ? 0 : 1);
})();
```

`открыть` сам подкладывает настройки и состояние и закрывает всплывающее окно
«С чего начать» — оно перехватывает нажатия. Если окно и есть предмет
проверки, передайте `{ шаги: true }`.

Две вещи, на которых легко обжечься:

- **Баланс капает каждую секунду.** Сравнивайте суммы через `близко()`, а не
  на точное равенство.
- **Приложение раз в секунду пишет состояние.** Править `localStorage` у живой
  страницы бесполезно — правку затрёт до перезагрузки. Открывайте новую
  страницу с нужным состоянием.
